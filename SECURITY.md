# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability
reporting: <https://github.com/5omeOtherGuy/keys-sync/security/advisories/new>.
Do not open a public issue for a vulnerability, and never include a real key
in a report. A key value appearing in output, logs, process arguments or
backup files, a store written with permissions wider than 600, or a key
written to the wrong store or entry counts as a vulnerability.

You will get an acknowledgement within 7 days. Fixes are prepared in a private
security advisory, released, and then the advisory is published with credit
to the reporter.

## Supported versions

The latest minor version is supported. Until the first release, that is the
latest commit on `main`.
